# Reports

Analytical write-ups that synthesize one or more company profiles.

## Conventions

- Filename: `<topic-kebab>-YYYY-MM.md` (optional day suffix)
- Reference companies by stable `id` (e.g. `anthropic`, `cursor`)
- Separate **facts** (from profiles/evidence) from **judgments** (scores and narrative interpretation)
- Include a limitations section
